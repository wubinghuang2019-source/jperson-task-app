# J 人任务 App 🎯

**智能任务管理助手** - 专为 MBTI J 型人格设计

---

## 🌟 核心功能

- ✅ AI 智能整理（语音/文字输入，自动分类）
- ✅ 多视图展示（时间轴/甘特图/看板/日历）
- ✅ 进度追踪（实时更新，可视化进度条）
- ✅ 手帐风格详情页（精美皮肤，VIP 解锁）
- ✅ 智能提醒（自动配置，不错过重要节点）

---

## 🛠️ 技术栈

- **前端**: HTML5 + Tailwind CSS + Vanilla JavaScript
- **部署**: Vercel（静态托管）
- **设计**: 移动端优先，响应式布局

---

## 🚀 快速开始

### 本地预览

```bash
cd "J 人任务 App"
python3 -m http.server 8080
```

然后访问 http://localhost:8080

### 生产部署

已配置 Vercel 自动部署：
1. 推送到 GitHub
2. Vercel 自动构建
3. 获得公开访问链接

## 🎨 设计原则

- **移动优先**: 单列布局，触摸友好（44x44px 最小点击区域）
- **视觉层次**: 大胆字号对比，清晰信息层级
- **即时反馈**: 加载状态，点击动画，乐观更新
- **无障碍**: 语义化 HTML，键盘导航支持
